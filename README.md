# Справка Letterly — help.letterly.app

Это сайт справки Letterly: статьи «как сделать» и ответы на частые вопросы.
Сайт статический (готовые HTML-страницы, сервер не нужен). Собран на Astro, оформление перенесено из утверждённого макета `design/help_center_v7.html`.

## Как запустить у себя

Нужен Node.js 22 или новее.

```
npm install        # один раз — скачать зависимости
npm run dev        # сайт на http://localhost:4321 (поиск здесь не работает)
npm run build      # собрать сайт в папку dist/ + поиск + проверка ссылок
npm run preview    # открыть собранный сайт (здесь поиск работает)
npm run check      # проверка кода и сборка — запускать перед публикацией
```

## Где что лежит

- `src/content/articles/` — статьи. Одна статья = один файл `.mdx`. Имя файла = адрес: `tags.mdx` → `help.letterly.app/tags/`.
- `src/data/categories.ts` — разделы и группы (названия, порядок, иконки, подписи карточек).
- `src/data/faq/` — вопросы на главной, один файл на вопрос.
- `src/data/site.ts` — почта поддержки, ссылка «Open Letterly», «популярные темы» на главной.
- `public/images/` — картинки, `public/video/` — видео. Папка `public/images/help-center/` ждёт 24 файла от Даши.

## Как устроена статья

В начале файла, между строками `---`, — служебный блок: заголовок, короткое описание, раздел (`category`), группа (`group`), порядок, платформы, похожие статьи (`related`), дата, черновик (`draft`), скрытая (`hidden`), синонимы для поиска (`aliases`).
Если в этом блоке ошибка (нет заголовка, неверный раздел, ссылка на несуществующую статью), сайт не соберётся и напишет, что не так.

Дальше — обычный текст в Markdown и простые блоки: `<Callout type="tip|note|warn|safe">`, `<Steps>`, `<PlatformTabs>` + `<Platform name="mac">`, `<Figure>`, `<Video>`, `<Details>`, `<MoreLink>`. Примеры — в любой статье и в комментариях в `src/components/mdx/`.

## Перенос статей из макета

`node scripts/convert.mjs --list` — список всех статей макета.
`node scripts/convert.mjs --only tags,search` — перенести выбранные; `--all` — все; `--force` — перезаписать уже перенесённые.
Английский текст переносится без изменений. Скрипт пишет, что пропустил (заглушки скриншотов, ещё не перенесённые «похожие статьи»).
