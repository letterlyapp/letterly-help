Letterly runs on your phone, your computer, and in the browser. Your notes are the same everywhere.

<Callout type="note">

One subscription covers all your devices. See [How many devices can I use?](/how-many-devices-can-i-use/)

</Callout>

| Platform | Where to get it |
| --- | --- |
| **iPhone, iPad** | [App Store](https://apps.apple.com/app/letterly-voice-to-clear-text/id6464049772) |
| **Android** | [Google Play](https://play.google.com/store/apps/details?id=com.draftai) |
| **Mac** | [Mac App Store](https://apps.apple.com/app/letterly-ai-voice-note-taking/id6464049772) |
| **Windows** | [Microsoft Store](https://apps.microsoft.com/detail/9n0fkgsz4x60) |
| **Apple Watch** | Installs with the iPhone app |
| **Web** | [web.letterly.app](https://web.letterly.app) — any browser, nothing to install |

<Callout type="note" title="Is there a dictation button in the web version?">

No. Dictation works in the iPhone, Android, Mac and Windows apps. In the web version you can record notes and work with them, but there is no dictation button.

</Callout>
