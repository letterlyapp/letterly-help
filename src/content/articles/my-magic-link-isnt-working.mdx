The email we send contains a **magic link**, and on iPhone also a **6-digit code**. Both follow the same rules.

- They are valid for **15 minutes**. If more time has passed, request a new email in the app.
- Each can be used **only once**. If you have already used one, request a new one.
- Use them on the **same device** you started the login from — a link requested on your phone will not work if you open it on your computer.

<Callout type="note">

On iPhone, if the link keeps failing, use the code instead: on the **Check your email** screen tap or click **Enter code manually** and type the 6 digits.

</Callout>
