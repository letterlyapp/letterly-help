Letterly can translate a note into another language. The translation is saved as a separate version, so your original text stays untouched.

## Translate a note

<Steps>

1. Open the note and tap the **⋯** menu.
2. Choose **Translate**.
3. Pick the language you need.

</Steps>

<Figure src="/images/help-center/note-menu-translate.png" alt="⋯ → Translate" caption="⋯ → Translate" />

The translated version appears in the note in a few seconds.

## Work with the versions

Swipe left and right to move between the original and the translation, or tap the version name at the top of the note to pick one from the list.

Version names show the path the text took — **Meeting Takeaways / Spanish** means the note was rewritten first, then translated.

<Callout type="tip">

Translate the version you actually need. Rewrite the note first, then translate the result, so the translation carries the final wording.

</Callout>

## Translation is not the speaker's language

These two settings solve different problems:

| Setting | What it does |
| --- | --- |
| **Speaker's language** | Tells Letterly which language you spoke, so the transcript comes out right |
| **Translate** | Converts a finished text into another language |

If the transcript itself came out in the wrong language, set the **Speaker's language** in the note settings instead of translating it.
