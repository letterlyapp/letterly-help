A **note** is everything Letterly keeps from one recording: the audio, the transcript, and every version you create from it. Notes are also created when you type text by hand.

<Callout type="note">

On the **Free** plan you can keep up to **10 notes** in total.

<MoreLink href="/what-plans-are-there/">Learn more about plans →</MoreLink>

</Callout>

This article is a map of the three screens you move through: your notes, the recording screen, and the note itself.

## The notes screen

Everything you record lives here.

<Figure src="/images/help-center/notes-screen.png" alt="The notes screen" caption="The notes screen" />

| Control | What it does |
| --- | --- |
| **Record** | Starts a new recording |
| **+** | Adds a text note, or uploads an audio file to transcribe |
| **Search** | Finds notes by the words they contain. See [Search](/search/) |
| **Sort** | Orders notes by last update or creation date. See [Sorting](/sorting/) |
| **Tags** | Groups notes by label. See [Tags](/tags/) |
| **Settings** | Your account, languages, rewrite options, and integrations |

## Select notes in the list

Press and hold a note to select it. You can select several notes at once, and then:

<Figure src="/images/help-center/notes-select-mode.png" alt="Selection mode: Add tags, Merge, Delete" caption="Selection mode: Add tags, Merge, Delete" />

| Action | What it does |
| --- | --- |
| **Merge** | Combines the selected notes into one. See [Merge notes](/merge-notes/) |
| **Add Tags** | Adds the same tag to every selected note. See [Tags](/tags/) |
| **Delete** | Removes the selected notes permanently. See [Delete a note](/delete-a-note/) |

## The recording screen

| Control | What it does |
| --- | --- |
| **Stop** | Ends the recording and starts transcription |
| **Pause** | Pauses so you can think, tap again to continue |
| **Restart** | Starts the recording over. What you said is not saved |
| **Back** | Leaves the screen without saving the recording |
| **Multi-speaker** | Splits the transcript by speaker. See [Can Letterly separate speakers?](/can-letterly-separate-speakers/) |

<Callout type="note">

You can close the app while a note is transcribing. Letterly finishes in the background and the note appears when it is ready.

</Callout>

## The note

<Figure src="/images/help-center/note-screen.png" alt="The note screen and the ⋯ menu" caption="The note screen and the ⋯ menu" />

| Part | What it is |
| --- | --- |
| **Audio player** | Plays your original recording. See [Listen to the audio](/listen-to-the-audio/) |
| **Title** | Generated automatically after transcription, editable at any time |
| **Transcript** | What you said, as text. See [Edit note text](/edit-note-text/) |
| **Versions** | Rewrites and translations, kept alongside the original |
| **Tags** | Optional labels for grouping |
| **Copy** | Puts the text on your clipboard |
| **Rewrite** | Reshapes the text into another format. See [Rewrite options](/rewrite-options/) |
| **Actions** | Sends the note to other tools via Zapier or webhooks |

## The ⋯ menu

Everything else you can do with a note is in the **⋯** menu.

| Action | What it does |
| --- | --- |
| **Record more** | Adds another recording to this note |
| **Translate** | Translates the note into another language |
| **Share with** | Sends the text to another app |
| **Export audio** | Saves or shares the recording |
| **Speaker's language** | Sets the language you spoke, and transcribes the note again |
| **Add speaker roles** | Splits the transcript by speaker |
| **Archive** | Moves the note out of the list without deleting it |
| **Add to Dictionary** | Saves the selected word so it is spelled correctly next time. Available when a word is selected |
| **Text replacements** | Opens your saved spoken shortcuts |
| **Delete this note** | Removes the note permanently |
