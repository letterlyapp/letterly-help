Any note can be edited by hand, including the transcript and any rewritten version.

## Edit a note

<Steps>

1. Open the note and tap the text.
2. Make your changes.
3. Tap the **checkmark in the top-right corner** to save the text.

</Steps>

Edits apply only to the version you are viewing. Other versions of the note stay as they were.

<Callout type="warn">

Editing the text does not change the recording. The audio stays as it was.

</Callout>
