If another app already uses the same key combination, that app wins and Letterly never starts recording. The fix is to give Letterly a different shortcut.

<Steps>

1. Open **Settings → Dictation → Set shortcut**.
2. Press the new combination you want to use.
3. Try it in any text field.

</Steps>

<Callout type="tip">

Pick something that is unlikely to be taken — a function key you do not use, or a combination with two modifiers.

</Callout>

On Mac, also check **System Settings → Keyboard → Keyboard Shortcuts** and your other apps for the same combination.
