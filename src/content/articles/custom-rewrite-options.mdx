If none of the ready-made options give you the text you want, create your own. A custom option is a name plus an instruction in your own words, saved for reuse.

<Callout type="note">

Custom rewrite options are available on **Pro**. On the Free plan you have the **Magic** option.

<MoreLink href="/what-plans-are-there/">Learn more about plans →</MoreLink>

</Callout>

## Create an option from scratch

<Steps>

1. Open your list of rewrite options and tap or click **+ New**.
2. Choose **Create from scratch**.
3. Enter a **Name** — this is what you will see in the Rewrite panel, for example *Legal*.
4. Write the **Prompt** — the instruction Letterly follows, for example *Rewrite as if written by a lawyer*.
5. Tap or click **Save**.

</Steps>

<Figure src="/images/help-center/rewrite-create-custom.png" alt="+ New → Create from scratch, then name the option and write the prompt" caption="+ New → Create from scratch, then name the option and write the prompt" />

The option appears in your list and can be used on any note from now on.

<Callout type="tip">

The **+ New** menu also has **Choose from gallery** — a library of ready-made options you can add in one tap. See [Rewrite options gallery](/rewrite-options-gallery/).

</Callout>

## Write a prompt that works

- Describe the result, not the process: *Turn this into a short message to a client*.
- Name the format you expect: bullet points, subject line, greeting, length.
- Add your own rules: *Always use British spelling*, *Never use emojis*.
- Fix recurring mistakes: *The name is Katie, not Casey*.

A prompt can be up to 6000 characters, so it is fine to be specific.

## Start from an existing option

You can also copy an option you already use and adjust it, instead of writing a prompt from zero. See [Rewrite options panel](/rewrite-options-panel/).
