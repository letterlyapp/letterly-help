Tags group related notes — by project, client, or topic — so you can open one group instead of scrolling the whole list. A note can have several tags, or none.

## Add a tag from the note

<Steps>

1. Open the note.
2. Tap the **tag** icon on the left.
3. Choose an existing tag, or create a new one.

</Steps>

## Add a tag from the notes screen

<Steps>

1. Press and hold the note in the list.
2. Choose **Add Tags**.
3. Choose an existing tag, or create a new one.

</Steps>

To tag several notes at once, select them all before choosing **Add Tags**.

## Filter notes by tag

On the notes screen, tap a tag to see only the notes that have it. Tap it again to return to the full list.

## Manage your tags

Open **Settings → Tags** to rename tags, delete them, or change the order they appear in.

<Callout type="tip">

Put the tags you use most at the top of the order — that is the order they appear in on the notes screen.

</Callout>
