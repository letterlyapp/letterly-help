You can create a note by typing instead of recording. Text notes work exactly like recorded ones.

<Callout type="note">

Text notes count towards the note limit. On the **Free** plan you can keep up to **10 notes** in total.

<MoreLink href="/what-plans-are-there/">Learn more about plans →</MoreLink>

</Callout>

## Create a text note

<Steps>

1. On the notes screen, tap **+**.
2. Choose **Text note**.
3. Type your text. The note is saved automatically.

</Steps>

<Video src="/images/help-center/write-text-note.mp4" caption="Creating a text note" />

Text notes support rewrite options, translation, tags, and sharing.

<Callout type="tip">

To reshape text you already have, paste it into a text note and tap **Rewrite**.

</Callout>
